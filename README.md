# Travel Assistant

An AI travel planner built as a Streamlit in Snowflake app. It uses **Snowflake Cortex** with the `snowflake-arctic` LLM to write personalised travel itineraries.

## Features

- Enter your name, budget, travel preferences and past destinations
- Optionally add a starting location and the places you want to visit
- Get a personalised plan with destinations, flights, accommodation and activities, generated by `snowflake.cortex.complete`

## Tech stack

Python, Streamlit (in Snowflake), Snowpark, Snowflake Cortex (Arctic LLM)

## Getting started

This app runs inside Snowflake because it uses `get_active_session()`:

1. In Snowsight, create a new **Streamlit app**.
2. Paste in the contents of `app.py`.
3. Make sure your role can use Snowflake Cortex functions.
